## Project Overview
BrightFix Electrical Solutions is a fictional electrical services business based in Johannesburg, South Africa. The website was created to showcase the company’s services, improve online visibility, and provide a simple way for customers to contact the business.

## Website Goals
- Increase online visibility and attract potential customers
- Provide clear information about electrical services
- Make it easy for users to submit enquiries
- Ensure the website is responsive and user-friendly
- Improve accessibility and SEO for better discoverability

## Features
- Responsive design using HTML, CSS, and JavaScript
- Mobile-friendly layout for different screen sizes
- Contact and enquiry form with JavaScript validation
- SEO improvements such as meta tags and structured content
- Deployment through GitHub Pages

## Services Offered
- Electrical repairs
- Installations
- Maintenance services
- General electrical support
